# 化工单据管理系统 - 数据权限隔离完整方案

## 一、需求分析

### 1.1 需求目标
- 业务员只能查看和操作自己负责的数据
- 管理员可以查看全部数据
- 产品管理是公共数据，无需隔离

### 1.2 模块数据权限范围

| 模块 | 是否需要隔离 | 隔离规则 |
|------|-------------|----------|
| **客户管理** | ✅ 是 | 按 `customer.owner_user_id` 隔离 |
| **订单管理** | ✅ 是 | 按 `order.customer_id` → `customer.owner_user_id` 关联隔离 |
| **联系人管理** | ✅ 是 | 按 `contact.customer_id` → `customer.owner_user_id` 关联隔离 |
| **跟进记录** | ✅ 是 | 按 `customer_follow.customer_id` → `customer.owner_user_id` 关联隔离 |
| **供应商管理** | ✅ 是 | 按 `supplier.owner_user_id` 隔离 |
| **采购管理** | ✅ 是 | 按 `purchase_order.supplier_id` → `supplier.owner_user_id` 关联隔离 |
| **产品管理** | ❌ 否 | 公共数据，无需隔离 |
| **数据统计** | ✅ 是 | 按各业务模块的数据范围分别隔离 |

---

## 二、数据库改造

### 2.1 供应商表增加负责人字段

```sql
ALTER TABLE `supplier` 
ADD COLUMN `owner_user_id` INT UNSIGNED DEFAULT NULL COMMENT '负责人ID' AFTER `create_user_id`,
ADD KEY `idx_owner_user` (`owner_user_id`);
```

## 三、核心实现 - DataScopeService

### 文件位置
`backend/app/service/DataScopeService.php`

### 核心功能
1. 判断当前用户是否可以查看全部数据
2. 获取当前用户可访问的客户ID列表
3. 获取当前用户可访问的供应商ID列表
4. 应用数据范围过滤到查询
5. 检查单个资源的访问权限
