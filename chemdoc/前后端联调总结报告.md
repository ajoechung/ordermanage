### 2.3 后端跨域配置 (ThinkPHP 8.1)

已在 `app/middleware/CorsMiddleware.php` 中配置：

```php
// 允许的来源
$origin = $request->header('origin', '*');

// 允许的方法
$methods = 'GET, POST, PUT, DELETE, OPTIONS';
$headers = 'Content-Type, Authorization, X-Requested-With';

// 设置响应头
header("Access-Control-Allow-Origin: {$origin}");
header("Access-Control-Allow-Methods: {$methods}");
header("Access-Control-Allow-Headers: {$headers}");
header("Access-Control-Allow-Credentials: true");
header("Access-Control-Max-Age: 1728000");
```

### 2.4 JWT认证配置

**后端配置 (config/jwt.php)**
```php
return [
    'secret' => env('JWT_SECRET', 'your-secret-key'),
    'expire' => env('JWT_EXPIRE', 7200),  // 2小时
    'algo' => 'HS256',
];
```

**前端请求拦截器** (utils/request.js)
```javascript
service.interceptors.request.use(config => {
  const userStore = useUserStore()
  if (userStore.token) {
    config.headers['Authorization'] = `Bearer ${userStore.token}`
  }
  return config
})
```

## 四、参数格式统一

### 4.1 日期格式

- **前端请求**: `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm:ss`
- **后端响应**: 使用Carbon对象，默认格式 `Y-m-d H:i:s`
- **统一处理**: 前端使用 `value-format` 属性格式化日期选择器

### 4.2 字段命名

采用 **下划线命名** (snake_case) 风格，保持前后端一致：

| 前端字段 | 后端字段 | 说明 |
|---------|---------|------|
| `customer_id` | `customer_id` | 客户ID |
| `create_time` | `create_time` | 创建时间 |
| `total_amount` | `total_amount` | 总金额 |
| `contact_name` | `contact_name` | 联系人姓名 |

### 4.3 分页参数

```javascript
// 请求参数
{
  page: 1,       // 当前页码
  page_size: 10  // 每页条数

// 响应格式
```

## 五、权限控制对接

### 5.1 后端权限机制

- 使用RBAC权限模型
- 用户通过角色组 (`auth_group_access`) 关联角色
- 角色通过规则 (`auth_group`) 关联权限
- 权限标识使用字符串，如 `customer`, `order`, `system`

### 5.2 前端路由守卫

```javascript
router.beforeEach(async (to, from, next) => {
  const userStore = useUserStore()
  
  // 1. 检查Token
  if (hasToken) {
    if (to.path === '/login') {
      next({ path: '/' })
    } else {
      // 2. 获取用户信息
      if (Object.keys(userStore.userInfo).length === 0) {
        await userStore.getInfo()
      }
      
      // 3. 权限检查
      if (to.meta.permission) {
        const hasPermission = to.meta.permission.some(p => 
          userStore.permissions.includes(p) || userStore.groups.includes(1)
        )
        if (!hasPermission) {
          ElMessage.error('无权限访问该页面')
          next({ path: '/403' })
          return
        }
      }
      
      next()
    }
  } else {
    // 4. 未登录跳转
    if (to.path === '/login') {
      next()
    } else {
      next(`/login?redirect=${to.path}`)
    }
  }
})
```

## 六、常见问题排查

### 6.1 跨域报错

**问题**: `Access-Control-Allow-Origin` 错误

**解决方案**:
1. 检查后端CORS中间件是否正确配置
2. 确保 `Access-Control-Allow-Headers` 包含 `Authorization`
3. 前端请求确保使用 `withCredentials: true`（如需要）

### 6.2 Token失效

**问题**: 登录后请求仍提示未授权

**解决方案**:
1. 检查Token存储是否正确
2. 确保请求拦截器正确设置 `Authorization` 头
3. 检查Token过期时间配置
4. 前端实现Token自动刷新机制

### 6.3 参数不匹配

**问题**: 后端接收不到参数或类型错误

**解决方案**:
1. 检查请求Content-Type
2. 使用 `qs` 库处理参数序列化
3. 后端验证器添加严格类型检查

### 6.4 数据渲染异常

**问题**: 表格数据为空或格式错误

**解决方案**:
1. 检查API响应数据结构
2. 确认字段名称大小写/下划线一致
3. 处理空数据情况

## 八、部署说明

### 8.1 后端部署

```bash
# 1. 安装依赖
cd backend
composer install

# 2. 配置环境
cp .env.example .env
php artisan key:generate
php artisan jwt:secret

# 3. 初始化数据库
php artisan migrate
php artisan db:seed

# 4. 启动服务
php think run -H 0.0.0.0 -p 8000
```

### 8.2 前端部署

```bash
# 1. 安装依赖
cd frontend
npm install

# 2. 开发环境
npm run dev

# 3. 生产构建
npm run build

# 4. 构建产物部署到 Nginx
```

### 8.3 Nginx配置示例

