## 二、数据表结构详细设计

### 2.1 admin_user（管理员用户表）

```sql
CREATE TABLE `admin_user` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL COMMENT '用户名',
  `password` VARCHAR(255) NOT NULL COMMENT '密码',
  `realname` VARCHAR(50) NOT NULL COMMENT '真实姓名',
  `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号码',
  `email` VARCHAR(100) DEFAULT NULL COMMENT '邮箱',
  `status` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '状态：1-启用 0-禁用',
  `last_login_time` DATETIME DEFAULT NULL COMMENT '最后登录时间',
  `last_login_ip` VARCHAR(50) DEFAULT NULL COMMENT '最后登录IP',
  `create_time` DATETIME NOT NULL COMMENT '创建时间',
  `update_time` DATETIME NOT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='管理员用户表';
```

**字段说明**:
- `id`: 用户ID，主键，自增
- `username`: 用户名，唯一，不能重复
- `password`: 密码，使用MD5加密存储
- `realname`: 真实姓名
- `phone`: 手机号码
- `email`: 邮箱地址
- `status`: 状态，1启用，0禁用
- `last_login_time`: 最后登录时间
- `last_login_ip`: 最后登录IP
- `create_time`: 创建时间
- `update_time`: 更新时间

### 2.3 admin_auth（权限表）

```sql
CREATE TABLE `admin_auth` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '权限ID',
  `auth_name` VARCHAR(50) NOT NULL COMMENT '权限名称',
  `auth_code` VARCHAR(100) NOT NULL COMMENT '权限标识',
  `parent_id` INT UNSIGNED DEFAULT 0 COMMENT '上级权限ID',
  `auth_type` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '权限类型：1-目录 2-控制器 3-方法',
  `sort` INT NOT NULL DEFAULT 0 COMMENT '排序',
  `is_show` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否显示：1-显示 0-隐藏',
  `create_time` DATETIME NOT NULL COMMENT '创建时间',
  `update_time` DATETIME NOT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_auth_code` (`auth_code`),
  KEY `idx_parent_id` (`parent_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权限表';
```

**字段说明**:
- `id`: 权限ID，主键，自增
- `auth_name`: 权限名称（如：用户管理、订单列表）
- `auth_code`: 权限标识，唯一（如：admin/user, order/index）
- `parent_id`: 上级权限ID，0表示顶级权限
- `auth_type`: 权限类型，1目录，2控制器，3方法
- `sort`: 排序，数字越小越靠前
- `is_show`: 是否显示在菜单，1显示，0隐藏
- `create_time`: 创建时间
- `update_time`: 更新时间

```sql
  `action_type` VARCHAR(20) NOT NULL COMMENT '操作类型：新增/编辑/删除/查询',
  `ip_address` VARCHAR(50) DEFAULT NULL COMMENT 'IP地址',
  `user_agent` VARCHAR(255) DEFAULT NULL COMMENT '浏览器信息',
  `request_params` TEXT COMMENT '请求参数',
  `create_time` DATETIME NOT NULL COMMENT '操作时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_module` (`module`),
  KEY `idx_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='操作日志表';
```

**字段说明**:
- `id`: 日志ID，主键，自增
- `user_id`: 操作人ID
- `username`: 操作人用户名
- `module`: 操作模块（如：用户管理、订单管理）
- `action`: 操作内容
- `action_type`: 操作类型（新增、编辑、删除、查询）
- `ip_address`: IP地址
- `user_agent`: 浏览器信息
- `request_params`: 请求参数
- `create_time`: 操作时间

## 六、安全建议

### 6.1 密码安全
- 密码使用MD5或BCrypt加密
- 建议使用强密码策略
- 定期更换密码

### 6.2 SQL注入防护
- 使用ThinkPHP的查询构造器
- 避免直接拼接SQL语句
- 对用户输入进行过滤验证

### 6.3 XSS防护
- 输出时进行HTML转义
- 富文本编辑器使用白名单过滤
