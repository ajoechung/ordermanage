# 化工单据管理系统需求文档

## 一、系统概述

### 1.1 项目背景
化工单据管理系统是一套面向化工企业的业务流程管理平台，旨在实现客户、订单、采购、供应商等核心业务的数字化管理，提高企业运营效率。

### 1.2 技术栈
- **后端框架**: ThinkPHP 5.1
- **PHP版本**: PHP 5.6
- **数据库**: MySQL 5.5
- **前端框架**: Bootstrap 4
- **架构模式**: 前后端不分离，后台管理

### 1.3 目标用户
- 系统管理员：负责系统配置、用户管理、权限分配
- 销售人员：负责客户开发、订单管理、客户跟进
- 采购人员：负责供应商管理、采购单操作

## 二、角色权限设计

### 2.1 角色定义

#### 2.1.1 管理员
- **角色标识**: admin
- **角色描述**: 系统最高权限管理者
- **权限范围**: 
  - 系统所有功能模块的完全访问权限
  - 用户账号管理（增删改查）
  - 角色权限配置
  - 系统参数配置
  - 操作日志查看
  - 数据备份与恢复

#### 2.1.2 销售
- **角色标识**: sales
- **角色描述**: 销售人员，负责客户开发和订单管理
- **权限范围**:
  - 客户管理（仅查看和编辑自己创建的客户）
  - 联系人管理（仅查看和编辑自己创建的联系人）
  - 订单管理（增删改查）
  - 客户跟进记录管理
  - 查看数据统计
  - 查看个人操作日志

#### 2.1.3 采购
- **角色标识**: purchase
- **角色描述**: 采购人员，负责供应商和采购单管理
- **权限范围**:
  - 供应商管理（增删改查）
  - 采购单管理（增删改查）
  - 订单查看（仅查看关联自己采购单的订单）
  - 查看数据统计
  - 查看个人操作日志

## 五、业务流程设计

### 5.1 销售流程

**流程概述**: 销售人员在系统中完成客户开发、订单创建、订单履约、发票管理的完整业务流程。

**详细流程**:

#### 5.1.1 客户开发
```
步骤1: 销售新增客户
├─ 操作: 点击"客户管理" → "新增客户"
├─ 输入: 客户名称、行业、联系人、电话、地址等信息
├─ 必填: 客户名称、行业、联系人、电话
└─ 结果: 创建客户记录，状态为"潜在客户"

步骤2: 新增联系人
├─ 操作: 点击"联系人管理" → "新增联系人"
├─ 输入: 联系人姓名、电话、职位、关联客户
├─ 必填: 姓名、电话、关联客户
└─ 结果: 创建联系人记录，关联到指定客户

步骤3: 客户跟进记录
├─ 操作: 在客户详情页面点击"添加跟进记录"
├─ 输入: 跟进内容、跟进时间、跟进方式
└─ 结果: 创建跟进记录，便于后续查看客户动态
```

#### 5.1.2 订单创建
```
步骤4: 创建订单
├─ 操作: 点击"订单管理" → "新增订单"
├─ 输入: 
│  ├─ 关联客户（从已有客户中选择）
│  ├─ 订单金额（数字）
│  ├─ 下单时间（日期时间选择）
│  ├─ 履约状态（默认"待确认"）
│  └─ 订单明细（可选）
├─ 必填: 关联客户、订单金额、下单时间
└─ 结果: 创建订单记录，自动生成订单编号

步骤5: 订单确认
├─ 操作: 编辑订单，更新履约状态为"已确认"
└─ 结果: 订单进入生产/执行阶段
```

#### 5.1.3 履约管理
```
步骤6: 更新履约状态
├─ 操作: 编辑订单 → 修改履约状态
├─ 状态流转: 待确认 → 已确认 → 生产中 → 已发货 → 已完成
└─ 结果: 实时跟踪订单执行进度

步骤7: 发票管理
├─ 操作: 编辑订单 → 修改发票状态
├─ 状态流转: 未开 → 已申请 → 已开具 → 已寄出
└─ 结果: 跟踪发票开具和寄送情况
```

### 5.2 采购流程

**流程概述**: 采购人员管理供应商和采购订单，支持两种采购场景：自主采购和订单关联采购。

#### 5.2.1 供应商管理流程
```
步骤1: 新增供应商
├─ 操作: 点击"供应商管理" → "新增供应商"
├─ 输入: 供应商名称、联系人、电话、地址等信息
├─ 必填: 供应商名称
└─ 结果: 创建供应商记录

步骤2: 供应商状态管理
├─ 操作: 编辑供应商 → 修改状态
├─ 状态选项: 正常 / 合作中 / 已终止
└─ 结果: 跟踪供应商合作关系
```

#### 5.2.2 自主采购流程
```
步骤3: 创建采购单
├─ 操作: 点击"采购单管理" → "新增采购单"
├─ 输入:
│  ├─ 关联供应商（从已有供应商中选择）
│  ├─ 采购金额（数字）
│  ├─ 下单时间（日期时间选择）
│  └─ 采购明细（可选）
├─ 必填: 供应商、采购金额、下单时间
└─ 结果: 创建采购单记录，自动生成采购单号

步骤4: 采购单履约
├─ 操作: 编辑采购单 → 更新履约状态
├─ 状态流转: 待确认 → 已确认 → 采购中 → 已到货 → 已完成
└─ 结果: 跟踪采购执行进度
```

#### 5.2.3 订单关联采购流程
```
步骤5: 查看关联订单
├─ 操作: 在订单详情中点击"创建采购单"
└─ 结果: 系统自动关联订单信息

步骤6: 创建关联采购单
├─ 操作: 系统自动带入订单信息
├─ 输入:
│  ├─ 关联供应商（选择）
│  ├─ 采购金额（从订单金额或手动输入）
│  ├─ 关联订单（自动带入或手动选择）
│  └─ 其他采购信息
└─ 结果: 创建采购单，自动关联原订单

步骤7: 双向状态同步
├─ 操作: 更新采购单状态
├─ 结果: 可在订单详情中查看关联采购单的执行状态
└─ 目的: 实现订单和采购单的协同管理
```

## 七、非功能需求

### 7.1 性能需求
- 页面响应时间 < 3秒
- 数据库查询优化，建立必要索引
- 支持100用户并发访问

### 7.2 安全需求
- 用户密码加密存储（MD5或BCrypt）
- 登录验证和权限控制
- SQL注入防护
- XSS攻击防护
- CSRF令牌验证

### 7.3 兼容性需求
- 浏览器兼容: Chrome、Firefox、Edge、IE11
- 分辨率兼容: 1024x768及以上

### 7.4 可维护性需求
- 统一的代码规范
- 完整的注释文档
- 错误日志记录
- 数据备份机制
