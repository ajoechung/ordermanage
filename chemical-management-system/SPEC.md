# 化工单据管理系统 - 项目规格文档

## 1. 项目概述

### 1.1 项目信息
- **项目名称**: 化工单据管理系统
- **项目版本**: v1.0
- **技术栈**: ThinkPHP 5.1 + PHP 5.6 + MySQL 5.5 + Bootstrap 4
- **架构模式**: 前后端不分离，后台管理系统

## 3. 数据库设计

4. admin_user_role - 用户角色关联表
5. admin_role_auth - 角色权限关联表
6. product_category - 产品分类表
7. product - 产品信息表
8. customer - 客户表
9. linkman - 联系人表
10. supplier - 供应商表
11. orders - 订单表（注意：order为MySQL保留字）
12. order_item - 订单明细表
13. purchase - 采购单表
14. purchase_item - 采购明细表
15. customer_follow - 客户跟进记录表
16. operation_log - 操作日志表
17. system_config - 系统配置表

### 3.2 初始化数据
- 默认管理员账号：admin / admin
- 销售账号：sales01 / admin
- 采购账号：purchase01 / admin
- 预置角色：管理员、销售、采购
- 预置权限：完整的菜单权限树
- 示例数据：产品分类、产品、客户、供应商、订单、采购单

## 4. 角色权限设计

### 4.1 角色定义
- **管理员(admin)**: 拥有所有权限
- **销售(sales)**: 客户管理、联系人管理、订单管理、数据统计
- **采购(purchase)**: 供应商管理、采购单管理、产品查看、数据统计

### 4.2 权限控制
- 基于角色的权限控制(RBAC)
- 会话验证
- 控制器级别的权限检查
- 管理员拥有所有权限

## 5. 业务流程

### 5.1 销售流程
1. 新增客户 → 2. 新增联系人 → 3. 创建订单 → 4. 更新履约状态 → 5. 管理发票

### 5.2 采购流程
#### 流程A（自主采购）
1. 新增供应商 → 2. 创建采购单 → 3. 更新履约状态

#### 流程B（订单关联采购）
1. 查看订单 → 2. 创建关联采购单 → 3. 更新采购单状态
